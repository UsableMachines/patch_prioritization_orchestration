What Is This App?

Patch Prioritization & Orchestration is a workflow platform that helps security and IT teams:

  • Rank patches by exploitability (EPSS), CVSS score, asset criticality, network exposure, and operational impact
  • Analyze patches using AI-powered threat intelligence enrichment
  • Generate rollout plans that minimize downtime while addressing the highest-risk patches first
  • Track deployment with step-by-step execution tracking and approval workflows

The platform supports multi-tenancy and role-based access control (RBAC), enabling multiple organizations and teams to work independently.

Prerequisites

Before you begin, make sure you have:

  • An account — You're logged in, so this is done!
  • AI Agent configured — For AI-powered analysis, set the KINDO_API_TOKEN and KINDO_AGENT_ID environment variables. {% if agent_configured %} Configured {% else %} Not Configured — Go to Settings {% endif %}
  • Asset inventory — A list of servers, endpoints, and systems you need to patch
  • Patch feed — CVE advisories, vendor bulletins, or patch metadata to import

5

AI-Powered Analysis

Once patches are added, use the Analyze button on any patch detail page to trigger AI-powered scoring. The Kindo agent evaluates:

  • Exploitability and active threat intelligence
  • Asset criticality and business impact
  • Network exposure and attack surface
  • Operational impact of deployment

Results include a priority score, risk level, detailed findings, and actionable recommendations.
